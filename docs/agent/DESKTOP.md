# macOS 桌面版

面向用户的安装、后台运行、授权回调和备份说明在[桌面版指南](../guide/desktop.zh.md)，改动这些行为时同步更新它和英文版。本文记录桌面版的实现与验证。

桌面版由 Tauri 2 承载共用 React 界面，直接调用 Rust 核心。一个本地用户可以管理多个账号、IN 和 OUT；无需启动服务器或设置管理密码。服务器仍使用独立管理登录与租户隔离。

## 构建与运行

需要 Bun、Rust、Xcode Command Line Tools 和 CMake。在仓库根目录运行：

```sh
bun install --frozen-lockfile
bun run desktop:build
```

应用位于 `target/release/bundle/macos/Codex RC Bridge.app`，可以直接打开或复制到 Applications。开发模式运行 `bun run desktop:dev`，使用独立前端端口 15174；开发终端需保持运行。打包后的应用不依赖终端或 Vite。

首次进入设置页，保存直连或 HTTP 代理，再到账号页添加账号。配置 IN/OUT、配对、绑定和启动的操作与网页相同。代理设置仅影响此桌面应用。

macOS 菜单栏入口是单色双向箭头图标。关闭窗口会隐藏界面和 Dock 图标，桥接继续运行；从菜单栏“打开 Codex RC Bridge”或再次打开应用，会恢复窗口及 Dock 图标。通过菜单栏“退出并停止桥接”或应用退出命令停止整个应用。退出会等待已接收操作及桥接清理；已启用的绑定保存在数据库中，下次启动由共用协调器恢复。

## 授权回调

“打开授权页面”使用系统浏览器，也可以复制链接。应用先尝试监听本机 1455 端口，占用时回退到 1457，再用实际监听端口生成 `http://localhost:<端口>/auth/callback` 授权回调地址；匹配本次授权的端口和 state 后交给共用核心校验和保存。完成结果在应用中显示。

当 1455 和 1457 均已被其他程序占用时，界面明确提示复制浏览器最终的完整回调地址并手动提交。取消、完成或过期后，没有其他待授权事务时释放监听端口。此监听不提供管理 API；本地管理使用 Tauri IPC。

## 数据与秘密

- SQLite：`~/Library/Application Support/com.geniucker.codex-rc-bridge/bridge.sqlite`。
- 数据库主密钥：macOS 登录钥匙串，服务 `com.geniucker.codex-rc-bridge`，账号 `desktop-database-key`。
- 长期令牌和租户种子由共用 Vault 加密保存；IN/OUT 身份及密钥沿用共用核心的派生规则。
- 与现有服务器、验收环境和 Python PoC 使用不同的状态目录，不自动导入它们的账号。

备份前明确退出应用，再备份数据库。恢复原身份需要数据库和原钥匙串条目同时可用；仅复制数据库到另一台电脑还不能解密。已有数据库而原密钥不可读时启动失败，不生成替代密钥。当前尚未提供跨电脑的密钥导出/导入界面。

## 验证范围

2026-11-08：桌面服务测试覆盖本地租户约束、代理修改不改变身份、停止后拒绝操作，以及回调 Host/state 校验、一次性消费和失败结果。Playwright 使用模拟 Tauri IPC 检查桌面入口、系统浏览器授权调用和自动完成反馈；现有 19 项网页测试和新增 1 项桌面 IPC 测试通过；桌面 Rust 测试、工作区及启用 app 特性的 Clippy 均通过。macOS 原生调试应用已验证启动、重新启动、关闭窗口后继续运行、重新显示窗口及明确退出。release 应用包（约 21 MiB）也已验证启动、读取原钥匙串配置及明确退出。原生检查使用空白桌面配置。

2026-11-09：用户确认从网页迁移已有授权后实际使用正常。关闭窗口及从 Finder 重新打开已验证：同一进程的系统类型依次为 `Foreground → UIElement → Foreground`，重新打开后两条链路均显示连接可用。此前菜单栏图标不可见由用户确认是 Dimble 隐藏所致；使用菜单栏整理工具时需让 Codex RC Bridge 的入口显示出来。

桌面中新建账号的自动授权回调、配对全流程仍需真实账号验收。当前桌面交付目标为 macOS；Windows/Linux 系统凭据适配与 GUI 尚未完成。正式发布签名和公证尚未配置。

2026-11-09 审查修复：首次本地租户和加密身份种子改为同事务创建，写入失败可重新启动重试；已有身份缺失仍拒绝生成替代。授权状态区分等待、处理中、成功、失败和过期，完成结果自完成起保留十分钟；处理中不会因原授权期限到达而被误判过期。桌面 IPC 与网页 HTTP 共用错误分类，自动回调也返回具体失败原因。新增回归覆盖首次写失败恢复、临近到期的回调结果、终态停止轮询与错误提示。

2026-11-09 界面更新：App 标识不再触发首页跳转，网页使用 hash 导航保留当前页面；界面以英文为基础，默认跟随系统语言，支持中文及英文。App 在设置的通用区域选择语言，同步更新托盘菜单；网页在右上角选择。品牌图形与程序图标统一，托盘使用对应单色箭头并去掉 RC 文字。解除绑定需确认，账号检查在账号旁显示进度和结果。Playwright 覆盖导航历史、刷新、语言偏好与表单保留、解除绑定取消及确认、桌面设置和语言 IPC。
